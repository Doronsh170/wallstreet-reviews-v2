סקירות שווקים | וול סטריט וישראל

כלי להצגת סקירות שוק ממוקדות על וול סטריט וישראל, בשתי סקירות נפרדות בלבד: ישראל ווול סטריט. כל סקירה כוללת סיכום שבועי והכנה לשבוע הקרוב. הסקירות מרכזות אירועי מאקרו, מגמות שוק, סקטורים וחברות בולטות במבנה קצר, ברור ומקצועי.

הסקירות מופקות בסיוע כלי בינה מלאכותית, ולכן עלולות לכלול טעויות, אי־דיוקים או מידע שאינו מעודכן במלואו. הנתונים והאירועים נבדקים ככל האפשר מול מקורות חיצוניים, אך מומלץ לאמת מידע מהותי מול מקור רשמי.

מקורות מרכזיים: Reuters, Bloomberg, CNBC, Yahoo Finance, Federal Reserve, BLS, BEA, Bank of Israel, הבורסה לניירות ערך בתל אביב, מאיה, דיווחי חברות, וכן פרסומים רלוונטיים ב־X מחשבונות רשמיים ומקורות מקצועיים, בכפוף לאימות מול מקורות נוספים.

גילוי נאות

דורון שרייבמן, בעל רישיון יועץ השקעות מטעם רשות ניירות ערך. המידע באתר כללי ואינו מהווה ייעוץ השקעות ואינו תחליף לייעוץ המתחשב בנתונים ובצרכים האישיים; ככל שלא צוין אחרת, לכותב אין עניין אישי בנושא הפרסום.

הפקה: בוחרים ישראל או וול סטריט במסך הניהול. כל בחירה אוספת חומר לסיכום השבוע ולהכנה לשבוע הקרוב של אותו שוק. מעתיקים לצ׳אט ומפרסמים תשובת JSON אחת, הכוללת שני חלקים.

להפעלה ישירה: `python gather_combined_review.py israel_weekly_review` או `python gather_combined_review.py wallstreet_weekly_review`, ואז `python paste_review.py`.

הסקירות הישנות נשמרות בארכיון. הלשוניות הראשיות מציגות סקירה אחת לישראל וסקירה אחת לוול סטריט. הן ריקות עד לפרסום הראשון במבנה החדש. אין הפקה מתוזמנת, ההפקה לפי דרישה בלבד.

המסך משתמש בשמות הפעלה ששרת הניהול הקיים תומך בהם. אין צורך בפריסה נוספת של שרת הניהול.
