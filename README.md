סקירות שווקים | וול סטריט וישראל

כלי להצגת סקירות שוק ממוקדות על וול סטריט וישראל, בשתי סקירות משולבות בלבד: סיכום שבועי והכנה לשבוע הקרוב. כל סקירה כוללת חלק לישראל וחלק לוול סטריט. הסקירות מרכזות אירועי מאקרו, מגמות שוק, סקטורים וחברות בולטות במבנה קצר, ברור ומקצועי.

הסקירות מופקות בסיוע כלי בינה מלאכותית, ולכן עלולות לכלול טעויות, אי־דיוקים או מידע שאינו מעודכן במלואו. הנתונים והאירועים נבדקים ככל האפשר מול מקורות חיצוניים, אך מומלץ לאמת מידע מהותי מול מקור רשמי.

מקורות מרכזיים: Reuters, Bloomberg, CNBC, Yahoo Finance, Federal Reserve, BLS, BEA, Bank of Israel, הבורסה לניירות ערך בתל אביב, מאיה, דיווחי חברות, וכן פרסומים רלוונטיים ב־X מחשבונות רשמיים ומקורות מקצועיים, בכפוף לאימות מול מקורות נוספים.

גילוי נאות

דורון שרייבמן, בעל רישיון יועץ השקעות מטעם רשות ניירות ערך. המידע באתר כללי ואינו מהווה ייעוץ השקעות ואינו תחליף לייעוץ המתחשב בנתונים ובצרכים האישיים; ככל שלא צוין אחרת, לכותב אין עניין אישי בנושא הפרסום.

הפקה: בוחרים סיכום שבועי או הכנה לשבוע הקרוב במסך הניהול, אוספים את שני השווקים בפעולה אחת, מעתיקים לצ׳אט ומפרסמים תשובת JSON אחת.

להפעלה ישירה: `python gather_combined_review.py combined_weekly_summary` או `python gather_combined_review.py combined_weekly_prep`, ואז `python paste_review.py`.

הסקירות הישנות נשמרות בארכיון. הלשוניות הראשיות מציגות סקירות משולבות חדשות בלבד; הן ריקות עד לפרסום הראשון בכל סוג. אין הפקה מתוזמנת, ההפקה לפי דרישה בלבד.

שינוי רשימת המצבים בשרת הניהול מחייב גם פריסה של `worker/worker.js` ל-Cloudflare Worker הקיים.
